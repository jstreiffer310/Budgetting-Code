# AI Context System

**Purpose**: Rapid AI assistant onboarding and context acceleration for the Finance Automation system.

## 📁 Files Overview

### Core Context Files
- **`SYSTEM_DNA.md`** - Living architecture document with evolutionary history and critical fixes
- **`AI_ONBOARDING_GUIDE.md`** - Human-readable rapid onboarding guide for AI assistants
- **`ai_context_package.json`** - Machine-readable context data for programmatic use

### Tools
- **`ai_context_accelerator.py`** - Automated context package generator (updates the JSON and markdown files)

## 🚀 Usage Instructions

### For AI Assistant Sessions
1. **Quick Start**: Attach `AI_ONBOARDING_GUIDE.md` to provide rapid system context
2. **Deep Context**: Include `SYSTEM_DNA.md` for complete evolutionary history and architecture
3. **Programmatic**: Use `ai_context_package.json` for structured data integration

### Updating Context
```bash
cd AI-Context-System
python ai_context_accelerator.py
```

This regenerates the onboarding guide and context package with current system state.

## 🎯 Benefits

- **⚡ 90% faster AI onboarding** - From hours to minutes

- **📊 Data relationship mapping** - Function ↔ Data ecosystem documented
- **🔄 Self-updating system** - Easily refreshed after major changes

## 📋 Context Acceleration Strategy

Instead of explaining the entire system from scratch, simply reference:
1. System identity and scale
2. Recent major fixes and their context
3. Critical knowledge nodes (email processing, ML learning, data flow)
4. Common issues and solutions
5. AI assistant priorities

This transforms "getting an AI up to speed" from a lengthy process to a quick context injection.
